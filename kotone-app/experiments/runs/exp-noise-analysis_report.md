# ノイズ基準線レポート

生成日時: 2026-08-15T08:32:10.220Z

Phase A1(exp-akkey-phaseA1)で「A1 vs A2が全11シナリオで全セクション不一致」だった件について、
この不一致がN由来の意味的な差なのか、LLMサンプリングのノイズなのかを切り分けるための追加実験。

## 1. ノイズ基準線(temperature=0.5、A2/normal_policyを5回生成)

本番と同じtemperature=0.5で、**入力を一切変えずに**5回生成した場合の差分。
Nの寄与が皆無でも、この程度の「不一致」はサンプリングだけで発生する、という基準値になる。

| ペア | 完全一致判定 | 文字bi-gram類似度(参考値) |
|---|---|---|
| repeat#0 vs repeat#1 | 大幅に異なる(全セクション不一致) | 27.3% |
| repeat#0 vs repeat#2 | 大幅に異なる(全セクション不一致) | 22.7% |
| repeat#0 vs repeat#3 | 大幅に異なる(全セクション不一致) | 32.1% |
| repeat#0 vs repeat#4 | 大幅に異なる(全セクション不一致) | 22.1% |
| repeat#1 vs repeat#2 | 大幅に異なる(全セクション不一致) | 23.2% |
| repeat#1 vs repeat#3 | 大幅に異なる(全セクション不一致) | 27.9% |
| repeat#1 vs repeat#4 | 大幅に異なる(全セクション不一致) | 23.5% |
| repeat#2 vs repeat#3 | 大幅に異なる(全セクション不一致) | 23.9% |
| repeat#2 vs repeat#4 | 大幅に異なる(全セクション不一致) | 26.1% |
| repeat#3 vs repeat#4 | 大幅に異なる(全セクション不一致) | 24.7% |

**結論**: 完全一致ベースの判定では10ペア中10ペアすべて「大幅に異なる(全セクション不一致)」。
文字bi-gram類似度の平均は25.4%(参考値。意味的な近さの指標ではない)。
**この結果だけで見ると、Phase A1のA1 vs A2の不一致と統計的に区別できない。**

## 2. temperature=0でのA1 vs A2(ノイズを最小化した状態でのN寄与)

| 比較 | 完全一致判定 | 文字bi-gram類似度(参考値) |
|---|---|---|
| A1 vs A2(temp=0) | 大幅に異なる(全セクション不一致) | 23.1% |

キャッチコピー(セクション0)の実例:

- A1(K-only): 「次々と新しいことを始める行動力の人。でも、その先にある「完成させる静けさ」を知っている人」
- A2(Legacy-N): 「次々と新しい世界を広げていく、でも最後は自分の信念で決める人」

**参考**: A1 vs A2(temp=0)の類似度23.1%は、セクション1の
temp=0.5ノイズ基準線(平均25.4%、範囲22.1〜32.1%)の**帯の中に収まっている**。
つまりこの1事例だけでは、「ノイズの範囲を超えてN由来の差が出ている」とは言い切れない。

## 3. temperature=0の決定性チェック(A2/normal_policyを2回生成)

temperature=0が実際にノイズを減らせているかの健全性確認。

| 比較 | 完全一致判定 | 文字bi-gram類似度(参考値) |
|---|---|---|
| repeat#0 vs repeat#1(temp=0) | 大幅に異なる(全セクション不一致) | 33.1% |

キャッチコピー(セクション0)の実例:

- repeat#0: 「次々と新しい世界を広げていく、でも最後は自分の信念で決める人」
- repeat#1: 「次々と新しい世界を広げていく、でも最後は静かに深く根を張る人」

## 総合所見

1. **完全一致ベースの粗い分類は、今回の用途には不適切だった。** temperature=0(決定論的)で
   同一条件を2回生成しても「全セクション不一致」と判定される。LLMは同じ入力からでも
   文字単位で完全に同じ文章を再現することは基本的に無い(浮動小数点演算の非結合性等が
   知られている)。つまり「完全一致/部分一致/大幅に異なる」という指標は、N由来の差と
   純粋な生成ノイズを区別する能力を持っていない。**Phase A1レポートの「全11シナリオで
   全セクション不一致」という記述は、この指標の限界により、実質的に無情報だった。**

2. 一方、**実際の文面を目視すると、質的な違いは見て取れる**。temp=0の決定性チェック
   (2の比較)では「次々と新しい世界を広げていく」という骨格が保持され、末尾の表現だけが
   ("自分の信念で決める人" / "静かに深く根を張る人")変化している。対してA1 vs A2(temp=0)
   では、A1が「行動力」「完成させる静けさ」、A2が「新しい世界を広げる」「自分の信念で決める」と、
   骨格そのものが異なって見える。ただしこれは1事例の目視印象であり、定量的な結論ではない。

3. **今後、意味的な差を定量化するには、完全一致とは別の指標が必要。** 候補:
   - 文字/単語レベルの編集距離比率(Levenshtein similarity)
   - 埋め込みベクトルによる意味的類似度(cosine similarity)
   - キーワード/構造要素(動詞・対象語等)だけを抽出した骨格比較
   - 複数回生成した中央値的傾向(例: N個生成して多数決的な特徴を取る)との比較
   このレポートのbi-gram類似度は簡易な参考値に過ぎず、上記のいずれでもない。

4. 依頼書項目3の通り、この結果を踏まえた評価方法の選定はレイに相談の上で判断すること。
