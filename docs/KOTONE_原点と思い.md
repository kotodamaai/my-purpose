# KOTONE の原点と思い

> レイ・ルミナ・将来の協力者が、設計や文章で迷ったときに最初に読む文書です。
> コードの判断に迷ったら、ここに書いた「思い」に沿う方を選びます。
> 最終更新：2026-11-22（あっきーとルミナの対話から整理）

## 1. 原点

- KOTONE を作ろうと思ったきっかけは、**名前の音に「音象徴」を感じていた**こと。
- 音そのものが意味や印象を運ぶ、という考えは古代ギリシャのソクラテス（プラトン『クラテュロス』）にまでさかのぼる。あっきーの直感は、その系譜と同じ場所にある。
- 現代の言語学（音象徴研究）でも、濁音の「大きさ・強さ」、母音「あ」の「大きさ・開き」などは、言語を超えて再現される知見として扱われている。

## 2. 姿勢

- 魂・使命・輪廻転生は、今の科学では説明できない。だから**厳密性は求めない**。
- 占い・言霊・音象徴・数秘術など、人が長い時間をかけて言葉にしてきた枠組みを、敬意をもってまとめる。
- **円錐の原則**：解釈が流派ごとに違うのは、同じ円錐を上から見るか横から見るかの違い。見る角度の違いとして許容し、ズレは「ギャップ」「二面性」として表現に活かす。
- 既存の流派（水蓮流など）をそのまま使うのではなく、他の体系も含めて**学術っぽく整理し、オリジナルにする**。それが KOTONE らしさ。
- AI（ルミナ・レイ）に任せて着地点を見つけ、**早く完成させる**。

## 3. 伝えたいこと

- 「あなたは、**そういう可能性（特性）／使命を持って生まれてきている**」。
- 診断は断罪ではなく、気づき。読んだ人が「これ、わたしのことだ」と感じ、ワクワク・温かさ・安らぎ・興奮のいずれかで心が動くこと。
- **現象サマリー**は、その人の特性が好ましい形で発揮され、**周りの人がハッピーな気持ちになっている瞬間**を描く。影は「光と影」セクションで、光とセットで扱う。
- 同じ人には、何度診断しても同じ核を伝える（ぶれない診断が信頼になる）。

## 4. 名前の見方

- 50音の意味は、自分たちで作ったものを正本とする（見直すのは濁音・半濁音・拗音などの扱い程度）。
- **頭の音ほど重要**：日本人の名前は語尾（たろう・すけ・お・た・こ・み…）に共通の型が多い。重みは頭から 2/3 ずつ（完全5度の逆数）。
- **順番が重要**：「くみ」と「みく」は別の個性。
- **濁音**は、元の音を強く・濃く・荒く・重く・大きくする方向（4/3 倍＝完全4度）。係数には自然界の数列より、音楽の比率（ピタゴラス）を使う。ピタゴラスは数秘術の父でもある。
- **姓**は社会的インターフェース：内面の動きを社会に出すときの「出入口」。
- **名**は内部エンジン：その人の自然な動き方。
- 名の頭の音の意味を「この人の核」とする。
  - 「あ」は **創造性と開拓力**（「切り開く」方。旧表記「創造性と求心力」から変更予定）。
- 将来：芸名（姓名あり／名だけ）、商品名（チョコボールのように分けられないものは「名」として扱い、長い名前も判定できるようにする。姓の役割はなし）。

## 5. 誕生日の見方

- 名前と無理に融合せず、**切り分けて示す**。重なれば「より強く」、相反すれば「二面性」。
- 主役は **使命数**（ライフパス：年＋月＋日、11/22/33 を含む）＝使命。
- **誕生日の数**（日）＝才能（補助）。
- **月の数**＝育ちの土壌（人生前半の環境、補助）。
- 4 と 22 は動きの「保持」に割り当てる。
- 呼び名は流派で意味が揺れる「誕生数」を避け、「使命数／誕生日の数／月の数」とする。

## 6. 有償版で扱う予定のもの（今は組み込まない）

- **年代別の寄り添い**：利用者を4区分（学生・20代前後／アラサー／40〜50代／還暦以降）し、進学・就職・転職・結婚などのライフイベントの判断に寄り添う見せ方にする。
- **「いま迷っていること」**を選んでもらい、それに合わせて誕生日診断を語る。
- **相性診断**（Aさん→Bさん、Bさん→Aさんの非対称な語り）。
- 今は、無料版の**基本コンセプトを固める**ことを優先する。
